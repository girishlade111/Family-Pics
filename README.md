# Family Pics

A personal family photo collection repository — a place to keep and organize family pictures.

## About

This repository holds family photos and memories. Photos are organized in folders by event or date.

## Usage

- Add photos to a folder named after the event (e.g. `2026-diwali/`).
- Keep original quality; no compression applied to the originals.
- Optionally add a short `notes.md` in each folder describing the occasion.

## Tech stack

- No build step — plain file storage.

## Deploy notes

No deployment needed; this is a file-only repository.
